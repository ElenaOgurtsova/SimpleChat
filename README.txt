## Простой чат. Цель изучить применение C++ библиотек TCP Socket в LINUX. 
Серверная часть написана с использованием sys/socket.h, клиентская использует QT.
Приложение использует порт 8901.

## Серверная часть запускается либо на отдельном сервере либо в отдельной сессии (например ssh).
Запустить с параметром IP аддрес порта типа :
> ./SimpleChatServer 127.0.0.1

## Клиентская часть может быть запущена если поддерживается графика QT. QT приложение у меня не запустилось из сессии ssh. Для тестирования я создала командный файл runSimpleChatClient.sh с запуском 3-х клиентов в LINUX. Клиент использует QTCPSocket.

## Требования
Linux, C++20, cmake, QT.

## Сборка 
mkdir build // если нет
cd build
cmake ..
cmake --build .

## Запуск
Команда запуска сервера
> ./SimpleChatServer 127.0.0.1
Для остановки нажать Ctrl+C.

Для запуска клиента на этом же сервере
> ./SimpleChatClient 127.0.0.1
Для запуска с удаленного ПК передать IP сервера вместо локального адресса 127.0.0.1.
При запуске запрашивается имя пользователя. Сам пользователь записывается в список "Подключенные клиенты" и передается на сервер. С сервера передается список уже подключеннных клиентов. При подключении нового клиента он передается всем подключенным клиентам через сервер. Сообщение передается на сервер, сервер получает и передает все другим подключенным клиентам.
Для тестового запуска с одного ПК можно создать командный файл с запуском нескольких клиентов. Я создала runSimpleChatClient.sh.
